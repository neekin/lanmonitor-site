# 关于我们

LanMonitor 是一套自主研发的局域网桌面监控系统，专注于为获得明确授权的组织环境（企业终端管理、机房教学管理等）提供**稳定、透明、数据不出内网**的终端桌面管理方案。

## 我们的理念

- **数据主权在内网**：所有录像、截图、日志与账号数据保存在客户自己的服务器上，产品不依赖任何云服务，不上传任何数据到第三方。
- **离线可用**：授权签发、客户端接入、录像归档全流程均可在完全离线的内网环境完成。
- **透明合规**：客户端默认在任务栏显示受控托盘图标，产品明确不做隐藏进程、对抗杀毒软件等规避特性；我们相信监控工具的价值在于管理有序的场景，而不是隐蔽对抗。
- **兼容并蓄**：既要服务最新的 Windows 10 / 11 环境，也照顾仍有 Win7 设备的现实机房，双版本客户端长期同步维护。
