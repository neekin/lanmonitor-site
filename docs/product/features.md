# 核心功能

以下功能均已在当前版本交付，桌面管理端与 Web 服务端共享同一套接入、归档与授权核心。

## 屏幕采集与录像

### 无人值守自动录屏

- 客户端按配置自动分段录制屏幕（默认 2fps / 1280px，分段边界对齐整分钟与整点）。
- 录像自动上传归档，**无需有人实时盯着**；服务端按自然小时合并为 MP4，浏览器内直接播放。
- 画面无变化时跳帧省存储（时间压缩回放）；录制参数可远程下发调整。
- **断线补传**：服务端离线时录像暂存在客户端，重连后自动补传；缺失区间在回看页明确标出，不伪造画面。

### 实时屏幕查看

- 桌面端双击主机即观看实时画面（8~20fps 可调）；Web 端为浏览器 MJPEG 流，无需插件。
- 支持选择显示器查看（客户端上报显示器数量）。
- 远程鼠标键盘控制：在实时画面上直接操作对方计算机，含中文输入；需显式开启，仅主屏。

### 截图与归档

- 手动远程抓取高清截图（可选显示器），按主机归档保存。
- 定时归档截图：客户端按设定间隔自动上传全分辨率截图，按主机 / 日期浏览、打包导出。

## 设备管理

### 主机列表与缩略图

- 自动感知局域网内客户端上下线，展示主机名、用户名、IP、MAC、系统、分辨率与在线时长。
- 列表内嵌桌面缩略图预览，定时刷新，点击即进入实时画面。

### 进程与窗口监控

- 查看客户端进程名、窗口标题、内存占用与前台标记。
- 远程结束进程（桌面端右键 / Web 端主机行按钮），问题处理不再跑工位。

### 配置下发

- 单台 / 多台设备批量下发采集配置（录屏、缩略图、截图归档等参数）。
- 回执确认、失败重试、离线自动补发与配置持久化，每台设备可对比目标值与实际生效值。

## 服务端能力

### 自动发现与接入

- 服务端 UDP 广播宣告，客户端无需配置 IP 静默接入；支持访问密钥校验。
- 授权额度按在线连接计数，超额连接收到明确拒绝原因，断开后名额自动释放。

### 录像回看

- 每分钟上传，服务端按自然小时合并 MP4；缺段照常合并，显示覆盖时长与缺失区间，补传后自动重建。
- Web 端在线播放 / 下载，桌面端按主机 / 日期选择回看。

### 存储容量管理

- 可设存储配额（GB），超限按最旧文件优先自动清理；上传中的临时文件受保护。
- Web 端服务状态页查看实时用量。

### 客户端下载分发

- Web 登录页与免登录下载页提供现代版 / Win7 兼容版安装包；包内自带连接地址、端口与接入密钥。
- 桌面管理端同时提供局域网下载服务，客户机无需登录即可获取安装包。

## 稳定性与运维

### 防关闭机制（标准企业级）

| 机制 | 说明 |
|---|---|
| SYSTEM 服务 | 普通用户无权限停止或卸载，操作需管理员 |
| 崩溃自恢复 | 被杀 / 崩溃后 5 秒自动重启 |
| 开机自启 | 重启电脑后自动上线 |
| 断线静默重连 | 网络中断后指数退避重连，服务端未上线时静默等待 |
| 助手自愈 | 会话助手被结束 / 注销后 15 秒内自动重新拉起 |
| systemd（Web 端） | Linux 服务端开机自启 + 崩溃自动重启 |

### 客户端自动升级

- 稳定启动器 + 版本化核心 DLL，启动器加载核心承载采集、录制与连接逻辑。
- 升级清单使用 RSA 签名，校验类型、版本、大小与 SHA-256，拒绝降级和不安全包。
- 新核心写入独立目录，健康心跳稳定后才确认成功；**失败自动切回旧核心并恢复服务**。
- 管理端可对单台或多台设备主动检查更新。

### 卸载保护

- 可设置客户端卸载密码（8~128 字符，PBKDF2-SHA256 校验值独立保存），卸载需验证密码，错误不会停止服务。
- 新下载的安装包自动携带当前密码策略，修改密码无需重新安装客户端。
