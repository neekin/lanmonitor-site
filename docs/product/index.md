# 产品概述

LanMonitor 是一套**服务端 + 客户端**架构的局域网桌面监控系统，用于在获得明确授权的组织环境（企业终端管理等）中，掌握局域网内 Windows 终端的运行状况。

产品提供两种服务端形态与两种客户端形态，按需组合、开箱即用：

| 形态 | 说明 |
|---|---|
| 桌面管理端 | Windows 桌面程序，设备预览墙 + 日志，关闭窗口隐藏到系统托盘 |
| Web 服务端 | 浏览器访问，Windows / Linux / NAS 通用，自包含部署、无需安装 .NET |
| 现代版客户端 | Windows 10 / 11 x64，.NET 8 自包含运行时 |
| 兼容版客户端 | Win7 SP1 / Win8.1 / Win10 / Win11，x86 / x64，.NET Framework 4.8 |

## 系统架构

```
管理端（二选一或多开）
  ├─ 桌面管理端 Server.exe（WinForms）
  └─ Web 服务端 WebServer（浏览器 http://IP:9910）
        │  TCP :9901（长度前缀二进制协议，可设访问密钥）
        │  UDP :9902 自动发现
        ▼
客户端服务 Agent（Windows 服务，SYSTEM 权限）
   │  职责：TCP 连接 / 断线重连 / 心跳、会话助手管理、
   │        归档定时、录像暂存与上传
   ▼
会话助手（运行在登录用户的交互会话）
      职责：屏幕采集（实时帧 / 缩略图 / 截图）+ 无人值守分段录屏
```

**为什么要会话助手？** Windows 服务运行在 Session 0，与登录用户的桌面隔离，直接截图只能拍到空桌面。因此服务只负责网络与管理，屏幕采集由服务拉起的会话助手完成；用户注销、切换、锁屏后，服务会自动重新拉起助手。

## 服务端自动发现

客户端**无需配置服务端 IP**：服务端每 10 秒向局域网广播宣告（含 TCP 端口），客户端静默监听即可接入；服务端未上线时客户端静默等待、不报错，服务端一上线即在 10 秒内自动接入。也可在客户端配置中固定服务端地址，跳过发现流程。

## 部署要求

| 端口 | 用途 | 说明 |
|---|---|---|
| TCP 9901 | 客户端接入 | 长度前缀二进制协议，支持访问密钥 |
| UDP 9902 | 自动发现 | 服务端宣告广播 + 客户端探测 |
| HTTP 9910 | Web 管理页 | 仅 Web 服务端，可在配置中修改 |

- **桌面管理端**：Windows 系统，双击运行，内置 FFmpeg，开箱即用。
- **Web 服务端**：Windows / Linux / NAS 皆可，自包含单文件发布，无需安装 .NET；Linux 可注册 systemd 实现开机自启与崩溃自动重启。Linux/macOS 服务端需自行安装 FFmpeg（含 libx264）用于录像合并。
- **防火墙**：Linux 部署需放行上述三个端口。

## 安全设计

- Web 首次访问引导设置管理员账号，密码以 PBKDF2 哈希保存；登录态 8 小时有效。
- 写操作包含 CSRF 校验，初始化与登录接口限制请求频率。
- 客户端接入支持访问密钥；控制台、截图、录像与配置等管理功能均需管理员登录，仅客户端安装包提供免登录下载。
- license 与升级包采用 RSA-PSS / SHA-256 离线签名，手动篡改版本、数量或机器码都会导致验证失败。
- 所有数据保存在内网服务器本地，不依赖任何云服务。

## 路线图

以下能力已在规划中，将按优先级逐步交付：

1. **配置策略扩展**：分组继承、策略模板、历史版本回滚与定时应用。
2. **设备身份与分组**：持久化设备标识、主机备注、分组与最后上线时间。
3. **传输加密与操作审计**：HTTPS / TLS、服务端身份验证，记录配置修改、远程控制等操作。
4. **离线缓存与健康状态**：暂存容量与保留天数、上传限速、磁盘空间告警。
5. **录像检索**：可视化时间轴与事件检索。
